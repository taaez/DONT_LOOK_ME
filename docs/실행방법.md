# 실행 방법 — 사람 가림 프로그램 (`person_mask.py`)

카메라 영상에서 사람 영역을 찾아 불투명 단색으로 가리는 프로그램입니다. PC와 라즈베리파이 5에서 모두 실행됩니다.

기본 출력은 **왼쪽 원본 | 오른쪽 마스크 처리본** 분할 화면입니다.

> 현재 추론은 CPU로 합니다. AI HAT+(Hailo-8L)는 아직 사용하지 않습니다.
> 라즈베리파이 실행은 보드에서 아직 검증하기 전입니다. FPS는 직접 측정해서 확인하세요.

---

```

모든 명령은 저장소 최상위 폴더(`DONT_LOOK_ME/`)에서 실행합니다.
```

## 2. 라즈베리파이 준비

### 2-1. 하드웨어 연결 (전원을 끈 상태에서)

1. Active Cooler 장착
2. 카메라 케이블을 Pi 5의 **CAM/DISP 커넥터(22핀)** 에 연결하고, 반대쪽은 카메라(15핀)에 연결
3. microSD, 네트워크(Wi‑Fi 또는 랜선), 공식 27W 전원 연결

### 2-2. OS 설치 (PC에서)

1. [Raspberry Pi Imager](https://www.raspberrypi.com/software/) 설치
2. 장치 **Raspberry Pi 5**, OS **Raspberry Pi OS (64-bit)** 선택
3. 설정(톱니바퀴)에서 입력
   - 호스트명: `raspberrypi`
   - 사용자 이름과 비밀번호
   - Wi‑Fi 이름과 비밀번호 (랜선이면 생략)
   - **SSH 사용** 체크
4. microSD에 쓰고 Pi에 꽂은 뒤 전원 연결. 첫 부팅은 1~2분 걸립니다.

### 2-3. VS Code로 접속 (PC에서)

1. 확장 **Remote - SSH**(Microsoft) 설치
2. `F1` → **Remote-SSH: Connect to Host...** → `사용자이름@raspberrypi.local` 입력
   - 형식은 `사용자이름@주소`. `@` 앞이 Imager에서 정한 사용자 이름입니다.
3. 플랫폼은 **Linux** 선택, 비밀번호 입력
4. 왼쪽 아래에 `SSH: raspberrypi.local`이 보이면 연결된 것입니다. 이후 VS Code 터미널은 Pi 안의 터미널입니다.

접속이 안 되면 → [7. 문제 해결](#7-문제-해결)

### 2-4. 코드를 Pi로 옮기기

**방법 A: git clone (권장)** (Pi 터미널에서)

```bash
cd ~
git clone https://github.com/taaez/DONT_LOOK_ME.git
# 이후 수정사항 받기: cd ~/DONT_LOOK_ME && git pull
```

**방법 B: scp** (코드가 있는 PC의 터미널에서)

```bash
scp -r ./DONT_LOOK_ME 사용자이름@raspberrypi.local:~/
```

**방법 C: 드래그 앤 드롭**
Pi에 연결된 VS Code에서 **파일 > 폴더 열기**로 Pi의 홈 폴더를 연 뒤, 탐색기에서 `DONT_LOOK_ME` 폴더를 VS Code 왼쪽 탐색기로 끌어다 놓습니다.

복사 후 **파일 > 폴더 열기**로 `~/DONT_LOOK_ME`를 엽니다.

### 2-5. 카메라 동작 확인

```bash
rpicam-hello --list-cameras
```

카메라 이름(`imx708` 등)이 나와야 합니다. 안 나오면 케이블 방향과 삽입 상태를 확인하세요.

### 2-6. 환경 설치

```bash
cd ~/DONT_LOOK_ME
sudo apt update
sudo apt install -y python3-picamera2 python3-opencv
python3 -m venv --system-site-packages venv
source venv/bin/activate
pip install ultralytics
```

- `--system-site-packages`는 apt로 설치한 picamera2를 venv에서 쓰기 위한 옵션입니다. 빼면 `ModuleNotFoundError: picamera2`가 납니다.
- `pip install ultralytics`는 PyTorch까지 받아서 오래 걸립니다.
- 터미널을 새로 열 때마다 `cd ~/DONT_LOOK_ME` 후 `source venv/bin/activate`를 다시 실행합니다.

## 3. 실행

### 3-1. 모델 변환 (NCNN, 한 번만)

라즈베리파이 CPU에서 빠르게 돌리기 위해 모델을 NCNN 형식으로 변환합니다.

```bash
python src/person_mask.py --export ncnn --imgsz 320
```

`weights/yolov8n-seg_ncnn_model/` 폴더가 생깁니다. 변환에 쓴 `--imgsz`와 실행할 때 `--imgsz`는 같아야 합니다. 모델이나 해상도를 바꾸면 다시 변환하세요.

### 3-2. 실시간 분할 화면 (Pi 모니터 직접 연결 또는 VNC)

```bash
python src/person_mask.py --source picamera --weights weights/yolov8n-seg_ncnn_model --imgsz 320
```

`q`를 누르면 종료합니다.

### 3-3. 화면 없이 저장 (VS Code SSH 터미널)

SSH 터미널에서는 창이 뜨지 않습니다. FPS를 재면서 영상을 저장하세요.

```bash
python src/person_mask.py --source picamera --weights weights/yolov8n-seg_ncnn_model --imgsz 320 --no-show --save out.mp4
```

- 30프레임마다 평균 FPS가 출력됩니다. `Ctrl+C`로 종료하면 실행 요약(실제 경과 시간, AI 처리 FPS, 파일 재생 길이, 반복 기록 프레임 수)이 출력됩니다.
- 저장 영상은 **실제 시간에 맞춰** 기록됩니다. AI 처리가 `--fps`보다 느리면 새 프레임이 나올 때까지 직전 프레임을 반복 기록하므로, 영상이 빨리감기처럼 재생되지 않습니다.
- `out.mp4`는 VS Code 탐색기에서 우클릭 → **Download**로 PC에 받아서 봅니다.

### 3-4. 실제 장치 출력 (마스크만 전체화면)

```bash
python src/person_mask.py --source picamera --weights weights/yolov8n-seg_ncnn_model --imgsz 320 --single --fullscreen --fps 15
```

원본은 화면에 나오지 않고, 가려진 영상만 소형 디스플레이에 출력됩니다.

### 3-5. PC에서 실행

```bash
pip install -r requirements.txt
python src/person_mask.py --source 0                          # 웹캠
python src/person_mask.py --source video.mp4                  # 영상 파일
python src/person_mask.py --source image.jpg --save out.jpg   # 이미지 한 장
```

## 4. 옵션 정리

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--source` | `0` | 웹캠 번호, `picamera`(CSI 카메라), 영상/이미지 경로, 스트림 주소(`http://`, `rtsp://`) |
| `--weights` | `weights/yolov8n-seg.pt` | `.pt`, NCNN 모델 폴더, `.onnx` |
| `--imgsz` | `640` | 모델 입력 크기. 라즈베리파이는 320~416 권장. 작을수록 빠르고 작은 사람을 놓치기 쉬움 |
| `--conf` | `0.25` | 사람 판정 기준. 낮출수록 놓치는 사람이 줄고 오검출이 늘어남 |
| `--dilate` | `8` | 마스크 경계를 바깥으로 넓히는 픽셀. 윤곽 밖으로 삐져나오는 몸을 줄임 |
| `--color` | `40,40,40` | 가림 색 (B,G,R) |
| `--width`, `--height` | `640`, `480` | 카메라 입력 해상도 (웹캠, `picamera`) |
| `--fps` | `15` | 출력 FPS 상한. 처리가 더 느리면 그대로 두고, 빠르면 남는 시간만큼 쉼. `0`이면 제한 없음 |
| `--device` | 자동 | `cpu`, `0` 등 |
| `--log` | 없음 | 프레임별 진단 기록 CSV. `tools/analyze_log.py`로 분석 ([프레임진단.md](프레임진단.md)) |
| `--stream PORT` | 끔 | 브라우저 실시간 화면 (예: `--stream 8000` → `http://dontlookme.local:8000`). SSH 환경에서 화면 확인용. 분할 화면이면 원본도 전송되니 개발용으로만 |
| `--no-af` | AF 켜짐 | Camera Module 3 연속 자동초점 끄기 (기본은 켜짐, 끄면 초점 고정이라 흐려질 수 있음) |
| `--low-latency` | 꺼짐 | Picamera2 버퍼/큐를 줄여 오래된 프레임이 쌓이지 않게 함 (지연 비교용) |

## 5. 부가 기능

| 기능 | 옵션 | 설명 |
|---|---|---|
| 분할 화면 | (기본) | 왼쪽 `ORIGINAL`, 오른쪽 `MASKED`. 개발과 검증용 |
| 마스크만 출력 | `--single` | 원본이 화면에 나오지 않음. 실제 장치 출력용 |
| 분할 화면 크기 | `--view-width 1280` | 이보다 넓으면 축소. `0`이면 축소 안 함 |
| 전체화면 | `--fullscreen` | 소형 디스플레이 출력용 |
| 저장 | `--save 경로` | 보이는 화면 그대로 저장 (분할이면 분할 영상). 이미지는 `.jpg`, 영상은 `.mp4` |
| 화면 끄기 | `--no-show` | SSH 환경에서 FPS 측정용 |
| 모델 변환 | `--export ncnn` / `onnx` | 변환 후 종료 |
| 스트림 입력 | `--source http://...` | 네트워크 카메라 주소를 직접 지정 |
| 개/고양이 보존 | (기본) | COCO 사람 클래스(id 0)만 가림 |

### 안전장치 (fail-safe)

- 추론 중 오류가 나면 원본 대신 **검은 화면**을 출력합니다.
- 카메라가 프레임을 못 읽어도 종료하지 않고 **검은 화면**을 출력합니다.
- 마스크는 항상 **같은 프레임**의 추론 결과만 씁니다. 이전 프레임 마스크를 재사용하지 않습니다.

### 알려진 한계

- 오류가 없는데 사람을 **검출하지 못한 프레임**은 가려지지 않고 원본이 그대로 나갑니다. fail-safe는 오류에만 동작합니다. 연속으로 노출되는 프레임 수를 따로 측정해야 합니다.
- `--single`이 아니면 화면에 원본이 보입니다. 분할 화면은 검증용으로만 쓰세요.

---

## 6. 성능 측정 팁

- `.pt`와 NCNN을 각각 `--no-show`로 돌려서 평균 FPS를 비교합니다.
- `--imgsz`를 320 / 416 / 640으로 바꿔 보며 FPS와 사람 놓침 정도를 비교합니다.
- 목표는 15 FPS입니다. CPU만으로 부족하면 AI HAT+(Hailo)를 도입합니다.

## 7. 문제 해결

| 증상 | 확인 |
|---|---|
| VS Code에서 `raspberrypi.local` 접속이 안 됨 | Pi 전원을 켠 뒤 2~3분 기다렸는지, PC와 Pi가 같은 공유기에 있는지. 학교/기숙사 Wi‑Fi는 기기 간 통신을 막는 경우가 많음. `ping raspberrypi.local`이 안 되면 공유기 관리 페이지에서 Pi의 IP를 찾아 `사용자이름@192.168.x.x`로 접속 |
| `Connection refused` | Imager에서 SSH 사용을 체크했는지 |
| 비밀번호 거부 | 사용자 이름이 Imager에서 정한 것과 같은지 |
| `rpicam-hello`에서 카메라가 안 나옴 | 케이블 방향, 22핀↔15핀 케이블인지, 전원을 끄고 다시 연결 |
| `ModuleNotFoundError: picamera2` | venv를 `--system-site-packages` 없이 만든 경우. venv를 지우고 다시 생성 |
| 창이 안 뜸 / `cv2.imshow` 오류 | SSH 터미널에서는 창이 뜨지 않음. `--no-show --save`를 쓰거나 모니터/VNC에서 실행 |
| FPS가 너무 낮음 | NCNN으로 변환했는지, `--imgsz 320`으로 낮춰 보기 |
| 빨강/파랑 색이 뒤바뀜 | Picamera2 포맷은 `RGB888`이어야 OpenCV용 BGR 배열이 나옴(`BGR888`은 반대). 코드에서 `cvtColor`를 추가로 하면 다시 뒤바뀜 |
| 영상이 끊기고 전원 경고 | 공식 27W 어댑터를 쓰는지. PC USB로 전원을 주면 안 됨 |

참고: Pi 5의 USB-C 포트는 전원 입력 전용이고 USB-A 포트는 호스트 전용이라, USB 케이블로 PC와 직접 연결해서 SSH를 할 수 없습니다. 같은 네트워크(Wi‑Fi/공유기)나 랜선 직결을 사용하세요.
